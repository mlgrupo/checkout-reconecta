# Materiais do Asaas

Cole aqui tudo que vier do Asaas: documentação da API, PDFs comerciais, exemplos de webhook, kit de marca.

Sugestão de organização:

```
docs/asaas/
  api/          documentação técnica (PDF, MD, coleções Postman/Insomnia)
  comercial/    condições da parceria, taxas, contratos
  exemplos/     payloads reais de webhooks e respostas
```

Ao adicionar algo, atualize a seção "O que já sabemos" em `docs/06-integracao-asaas.md`.
